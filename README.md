# Green City Estate — Promotional Page

Official promotional information pack and site inspection booking portal for Green City Estate, managed by **Uyoinfomedia** as an authorized media partner.

## Overview
This standalone, lightweight landing page is designed to be embedded across digital partner applications and promotional channels via a "Click for More" link. It showcases masterplan details, zoning information, current site imagery, and a 24-month timeline, routing prospective buyers directly to the Uyoinfomedia desk via WhatsApp with a built-in referral tag.
